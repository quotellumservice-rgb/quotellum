Review planned versus actual results

Use the same scope and cost categories to explain a difference, rather than comparing mismatched numbers.

Audience: Consultants closing a project or milestone
Last updated: 2026-10-17

Freeze a baseline

Record the accepted scope, planned hours, cost assumptions and expected delivery date before work starts. Keep approved changes separate from the original baseline.

Collect actuals

Record time and expenses consistently. Distinguish approved extra work, rework, support and internal learning time. Avoid sending client information to public calculators.

Calculate a variance

If planned labor is 10 hours at $40 and actual labor is 13 hours at $40, the labor-cost variance is $120 unfavorable. Check whether scope changes generated additional revenue before drawing a conclusion.

Decide a next action

Was the gap caused by estimating, execution, missing information or a client change? Write one concrete action and an owner. A variance is evidence for a conversation, not an automatic performance verdict.
