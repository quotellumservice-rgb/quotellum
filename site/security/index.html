Home / Security overview and boundaries

Security begins with clear boundaries.

The public free website is a static site. It does not provide hosted accounts, private customer records or a payment service.

Controls in this public build

  • Calculator arithmetic runs locally, without a network-submission controller.
  • Only reviewed public files and the checksum-verified free workbook are included.
  • The site configuration contains no server functions or customer-data endpoints.
  • A restrictive content policy limits scripts to this site, disallows network connections and form submissions, and prevents embedding.
  • No private customer package, service credential or administrative console is published.

What this does not certify

These controls do not constitute an independent audit, security certification, regulatory approval or a guarantee against every vulnerability. This site makes no claim that hosted paid delivery, shared workspaces, backups or tenant isolation have passed release checks.

Report a concern

Email quotellum.service@gmail.com with the affected public page, a minimal reproduction and the expected behavior. Do not include credentials or other people’s data. Do not access private records, disrupt services or continue testing beyond authorized public behavior. No bounty or response-time commitment is offered.

Privacy and professional information

Please do not send sensitive client documents to the calculator or support mailbox. See the privacy explanation for actual data handling.
