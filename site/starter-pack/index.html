Free Starter Pack · Version 1.0

A better first quote, on your own device.

One complete job estimate, a blank template, a fictional worked example, three scenarios and a practical guide. No sign-up, card or purchase required.

Download the complete free Starter PackUse the online calculator

You can download individual files below. Spreadsheet applications are not included. This pack evaluates one job; it does not include the paid project-history or actuals tracker.

Use in Microsoft Excel

Download the .xlsx workbook. Start with the Start here sheet, review the fictional example, then enter one job in the blank template. Change only the marked inputs.

Download the workbook (.xlsx)

Use in Google Sheets

Download the .xlsx file, upload it to your Google Drive, then choose Open with Google Sheets. Save a Google Sheets copy if you want to edit it there. Opening a copy in Drive is your own cloud upload; Clariro does not upload it for you. Google Docs is for text, not spreadsheet formulas.

Get the Google Sheets import file

Use in Apple Numbers

Download the .xlsx workbook and open it in Numbers on a Mac, iPhone or iPad. Keep your original download. On a phone, switch to landscape or use the browser calculator when a spreadsheet is difficult to navigate.

Get the Numbers import file

Use in LibreOffice / OpenOffice

Open the .xlsx file in Calc. Check the worked example before using your own figures. Formatting, dropdowns and print layout can differ. No .ods edition is offered until that format has been tested.

Get the Calc import file

Print the quick-start guide

A printable guide with a checklist, definitions and examples. PDF works without a spreadsheet app. You can also copy the plain-text guide into Google Docs or another word processor.

Download the PDF guide

Use the offline browser calculator

Download this self-contained HTML file, then open it locally in a current browser. It is a separate one-job tool; its backup format is described in its own guide. No installation, login or network connection is needed for calculations.

Download the offline calculator

Choose the format you need

  • Read the printable guide in your browser.
  • Get the text guide for Google Docs or your preferred editor.
  • Get the simple CSV input starter. CSV is a portable table of inputs; it does not preserve workbook formulas, multiple sheets or formatting.
  • Read package contents, version and limitations.

Excel calculation checks and browser tests are reported for the actual files. Google Sheets, Numbers, LibreOffice and OpenOffice import instructions are provided; native calculations in those apps have not been independently certified. Compare your import with the workbook’s example before relying on it. Do not enable macros or send confidential client records to support.
